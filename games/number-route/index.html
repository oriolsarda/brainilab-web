How Number Route works

Number Route is a left-to-right arithmetic puzzle. You cannot reorder the four numbers and normal operator precedence does not apply. If you choose 1 + 2 × 3, the game calculates 1 + 2 first, then multiplies that result by 3.

One solution per puzzle

BrainiLab validates every published Number Route against all 64 possible three-operator combinations and only accepts puzzles with exactly one valid solution.

Number Route and the Daily

Number Route can appear as one of the rotating Daily games. The Daily format uses three routes and awards more points for faster solves, while Play Anytime keeps ten routes. Try First loads the same full Daily mechanic with a different batch and no score.
